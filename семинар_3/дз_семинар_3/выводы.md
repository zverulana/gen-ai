## 2. Где модель ошибалась

### 2.1. Примеры искажений цитат

Найдено 3 ghost-цитаты (не подтверждаются исходным текстом при проверке префикса):

1. R011: модель вернула обобщённую цитату "Стабильная работа, быстрые переводы и оплата ЖКХ", в исходном тексте это два отдельных фрагмента.

2. R019: модель вернула обобщение "Удобная навигация и быстрая поддержка", которого дословно нет в отзыве.

3. R019: повтор того же искажения во второй аспектной записи.

Вывод: даже при строгом промпте нужны автоматические проверки цитат и пост-фильтрация.

### 2.2. Пример действия judge

В текущем output/judge_report.json судья пометил все action items как supported
и не выдал weakly_supported/not_supported.

Пример действия judge из текущего прогона:

- Action item: "Добавить режим «минимум анимаций» и гибкую настройку главного экрана."
- Вердикт: supported
- Почему: в evidence приложены прямые цитаты из R005, R009, R029, R035.

Примечание по шаблону: пункт про пример weakly_supported/not_supported формально
не закрывается этим конкретным прогоном, потому что judge не выдал таких вердиктов.

## 3. Что бы изменили в production

### Что оставили бы как есть

- Структуру конвейера из 4 обязательных этапов (IE, aspects, MR, judge).
- Pydantic-валидацию с бизнес-инвариантами (дата, rating, Literal-поля).
- Санити-проверку цитат как обязательный quality gate.

### Что переделали бы

- Усилили бы этап IE:
  - добавить пост-правило "цитата должна быть точной подстрокой исходного отзыва";
  - снижать severity, если цитата короткая/неоднозначная.
- На этапе REDUCE добавили бы более строгий шаблон: один action item = минимум 2 независимых подтверждения.
- Для judge внедрили бы second-pass с другой моделью, чтобы снижать риск переоценки (all supported) и контролировать ложноположительные вердикты.

### Что добавили бы

- Prompt caching и контроль prompt_cache_hit_tokens
- A/B прогон на 2 моделях (генератор и судья разных семейств)
- Ручной аудит случайной выборки 10% отзывов для калибровки severity и support
- Автоматический fail, если ghost-цитаты > 10% или overall_score < 0.7
